Zum Organigramm

B_77 Cockpit · Modul-Dokumentation

Interaktives
Organigramm

Ein eigenständiges Cockpit-Modul, mit dem Kund:innen ihre Vertriebsorganisation per Drag-&-Drop aufbauen: Abteilungen und Funktionen anordnen, Personen mit Profil hinterlegen, Positionsfit bewerten und Verantwortlichkeiten sichtbar machen.

Modul: Organigramm Status: Autark / lokal Speicherung: localStorage + JSON Stand: Juni 2026
Aufbau01 — Oberfläche

Vier Bereiche

Die Oberfläche ist bewusst schlank gehalten: links die Vorrats-Bibliothek, in der Mitte das Board, ein Seitenpanel für Personen und eine Werkzeugleiste oben.

Links
Bibliothek

Vorrat an Abteilungen — jede mit ihren typischen Funktionen darunter. Quelle fürs Drag-&-Drop.

Mitte
Board / Canvas

Die Vertriebsleitung an der Spitze, darunter die Abteilungen mit Funktionen und Personen.

Rechts
Personen-Panel

Seitlich einfahrendes Panel zum Erfassen aller Angaben einer Person.

Oben
Werkzeugleiste

Abteilung hinzufügen, Drucken/PDF, Export, Import, Muster und Leeren — plus Auto-Save-Status.

Leistungsumfang02 — Funktionen

Was das Modul kann

Neun Kernfunktionen — vom Aufbau über die Pflege bis zur Auswertung und Sicherung.

01
Orientierung
Bibliothek mit Zuordnung
Jede Abteilung zeigt ihre zugehörigen Funktionen eingerückt darunter — so ist sofort klar, was wohin gehört. Ganz oben steht die „Leere Abteilung" für freie Strukturen.
02
Aufbau
Drag-&-Drop-Board
Erst die Abteilung in den oberen Bereich ziehen (sie kommt leer), dann ihre Funktionen einzeln hineinziehen. Gültige Drop-Zonen werden hervorgehoben.
Abteilungen sortierenFunktionen verschieben
03
Ergänzen
Frei hinzufügen & benennen
Über „+ Abteilung" und „+ Funktion" öffnet sich sofort ein Fenster zum Benennen. Eigene Bezeichnungen sind jederzeit möglich.
04
Profil
Personen erfassen
Je Funktion beliebig viele Personen mit Name, Verantwortung, Ausbildung und Länge der Zugehörigkeit — erfasst im Seitenpanel.
05
Bewertung
Positionsfit in %
Ein Regler bewertet die Eignung der Person für ihre Position (0–100 %). Der Wert erscheint als Balken direkt auf der Personenkarte.
06
Führung
Leiter:in per Stern
Ein ★ Stern markiert die Leitung einer Abteilung — maximal eine pro Abteilung. Sie wird im Abteilungskopf namentlich hervorgehoben.
07
Gliederung
Abteilungsfarbe
Jede Abteilung kann optional eine Farbe bekommen (Kopf-Oberkante). Standard bleibt neutral — für ruhige, einheitliche Organigramme.
08
Kopfbereich
Alles frei editierbar
Titel, Bereich, Beschreibung sowie Branche, Typ, Reichweite, Stand und die Vertriebsleitung sind direkt anklickbar und überschreibbar.
09
Sicherung
Speichern & Teilen
Auto-Save lokal im Browser. Export/Import als JSON, Drucken/PDF, Muster lädt ein Beispiel, Leeren startet neu.
Detail03 — Personenfelder

Pro Person

Diese Angaben lassen sich im Personen-Panel hinterlegen.

Name
Vor- und Nachname der Person.
Verantwortung
Aufgaben- und Verantwortungsbereich in der Funktion.
Ausbildung
Qualifikation / Abschluss, z. B. „Dipl.-Kffr." oder „B.A. Sales".
Zugehörigkeit
Länge der Zugehörigkeit, z. B. „seit 2018 · 8 Jahre".
Positionsfit

Kommentar

Technik04 — Datenmodell

Ein JSON-Objekt

Der gesamte Zustand ist ein einziges, sauber strukturiertes JSON-Objekt — identisch für Auto-Save, Export/Import und die spätere Anbindung ans Cockpit-Backend.

// vollständiger Zustand des Organigramms
{
  meta: { eyebrow, title, subline, chips: [ … ] },
  apex: { code, title, role },  // Vertriebsleitung
  departments: [
    {
      id, code, name, color,
      functions: [
        { id, name, persons: [
          { id, name, responsibility, education,
            tenure, fit, comment, isLeader }
        ] }
      ]
    }
  ]
}

Autark heute, anschlussfähig morgen. Aktuell speichert das Modul lokal im Browser (kein Server). Für das Cockpit-Backend wird dasselbe JSON-Objekt einfach pro Konto in einer jsonb-Spalte abgelegt — ohne Umbau der Datenstruktur.
